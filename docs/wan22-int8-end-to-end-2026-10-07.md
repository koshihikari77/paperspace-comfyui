# Wan2.2 INT8：prestep付き通し生成の結果（2026-10-07）

追加LoRA、色合わせ、2倍拡大、4倍フレーム補間、MP4保存まで1回の実行で成功した。
従来の工程を置き換える候補として接続確認は完了。ただし普段使用する個別LoRAの品質をすべて確認した結果ではなく、通常環境への導入も未実施。

## 実行条件

- RTX A6000 48GB、専用ComfyUIポート6007。通常6006は変更なし。
- native Wan2.2 High/Low INT8 ConvRot。CUDA INT8 linear実行を計3680回確認。
- 専用WanWrapperNativeSamplerでWrapperのDPM++ SDEスケジューラを使用。shift8。
- prestep1（CFG3.5）→High3（CFG2/1/1）→Low3（CFG1）。
- 旧Wan2.1 LightX2V：High強度3、Low1。prestepには適用しない。
- 正負分岐修正版NAG：11/.25/2.5。FETA1。
- CameraRotation LoRA .8をHighへ追加。prestepにも適用。
- seed22222、既存の人物画像、512×512、81フレーム、16fps。
- ColorMatch MKL .5 → 2x-AnimeSharpV4 Fast RCAN → RIFE49 4倍（fast/ensemble有効）→ H.264。

## 出力と確認

- 元動画：512×512、81フレーム、16fps、5.0625秒、無音。
- 完成動画：1024×1024、321フレーム、64fps、5.015625秒、無音。
- 321枚は(81−1)×4＋1。補間の終端処理により尺がわずかに異なる。
- 両MP4をFFmpegで全フレームデコードし、解像度・フレーム数・fps・音声なしを検証済み。
- 完成動画から4枚おきに抽出した81枚の一覧を目視確認。人物と室内が保たれ、以前の背景崩壊は確認されなかった。補間された全321枚の個別目視確認ではない。
- カメラLoRAによる強い画面回転が出ている。プロンプトの緩やかなorbitに完全一致するとの評価ではない。

## 判定と限界

prestepを維持したINT8生成と追加LoRA・後処理を同時に使用できた。従来工程を置き換える候補として成立する。
今回は前回確認済みのカメラLoRAによる工程確認であり、普段の個別制作LoRAをすべて再現したものではない。
FETA1は従来値を維持したもので、この実行で品質向上効果を切り分けてはいない。
旧LightX2VのWan2.2に存在しない画像分岐のキー警告は前段検証と同じであり、全キー適用とは扱わない。
